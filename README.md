# 🎤 TwoSecondsLater

A minimal web app that plays audio with a 2-second delay. Perfect for speech training, singing practice, or just having fun with delayed audio feedback.

![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ Features

- **Real-time audio delay** - Hear sounds exactly 2 seconds later
- **High-fidelity capture** - 96kHz/24-bit studio-quality audio
- **Zero installation** - Works directly in your browser
- **Echo cancellation** - Prevents feedback loops when using speakers
- **Beautiful UI** - Modern, responsive design with animations

## 🚀 Quick Start

1. Open `index.html` in your browser
2. Click the microphone button
3. Allow microphone access
4. Speak or make sounds - hear them 2 seconds later!

## 🎧 Best Experience

For the best experience, use **headphones** to prevent any potential audio feedback.

## 🛠️ Technology

- Pure HTML, CSS, and JavaScript
- Web Audio API for high-quality audio processing
- No dependencies or build steps required
